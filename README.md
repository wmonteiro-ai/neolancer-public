# Neolancer

**Neolancer** is a from-scratch, open-source game engine, written in Rust, that plays *Freelancer* (Digital Anvil / Microsoft, 2003) **using your own copy of the original game data**.

It aims for two things, in order:

1. **The same experience on a modern foundation.** Play the original game the way it felt, on current hardware and platforms, built on a clean, modern architecture.
2. **Then extend it.** New features, modding and quality-of-life improvements on top of a faithful base.

> **Status:** planning and early development. Nothing is playable yet.

## Targets

- **Platforms:** Windows, Linux / Steam Deck, macOS (Apple Silicon)
- **Graphics:** Vulkan; Metal on macOS

## What Neolancer is not

- It contains **no game assets and no code from the original game**, and never will. You need a legitimately obtained copy of Freelancer; Neolancer reads its data files.
- It is not affiliated with or endorsed by Microsoft or Digital Anvil. *Freelancer* is a trademark of Microsoft Corporation and is used here only to describe compatibility.
